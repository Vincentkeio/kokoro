# 黑金 1.0.4

参考 Jiwo Probe 黑金方向，为 Kokoro 的服务器监控界面制作的独立主题。

使用 `jiwo-blackgold-1.0.4.kokoro-theme` 导入。包内包含标准 `theme.json` 与压缩的 `assets/wallpaper.webp`，不含 CSS、脚本或远程资源。支持清单 v1、tokens v2 和布局 v1。

本版以 Jiwo Probe 的黑金方向为基础，使用墨绿黑表面、香槟金金属渐变与独立的绿／黄／红状态色，并更新为压缩 WebP 黑曜石金脉壁纸。首页卡片为三列，窄屏自动调整；采用直线图和紧凑详情页。地球关闭自动旋转。

兼容修复后的 Kokoro 会优先显示主题包自带的壁纸，站点全局壁纸作为未自带壁纸的主题的后备。导入本包不会改写站点壁纸设置。

标题栏与总览的结构依赖面板公共样式。旧版面板若将公共样式限定为 `kokoro.` 前缀，会漏掉导入主题；应更新公共样式兼容修复，不能通过主题添加任意 CSS 绕过规范。

壁纸由内置 image_gen 工具生成。提示词：墨黑底，外角分布克制的香槟金细弧线与细腻拉丝纹理，中央保留安静暗色留白，低对比，无文字、标志或界面元素，16:9 监控面板背景。

参考项目：https://github.com/chnnic/jiwo-probe
