# 后台程序更新

在后台 **系统 → 程序更新** 点击 **检查更新**。面板会读取本项目 GitHub 已发布版本（包含 Alpha / Preview），沿用管理菜单的版本比较规则；只有较新的版本才可更新。

- **更新面板**：确认后独立更新进程下载官方发布文件、校验 SHA-256 与程序架构，备份原程序和数据库，再替换程序并重启。启动检查失败时回退。更新期间页面短暂重连，完成后继续显示结果。
- **更新全部探针**：仅为落后于最新发布的节点下发更新。保留配置、令牌、节点名称和历史数据；节点重启后，实际新版本上报才算完成。显示逐节点结果，失败节点可再次检查并重试。
- 离线节点恢复上报后接收任务，整批任务最多等待 20 分钟，超时会明确显示失败。
- 刷新页面后仍可查看最近一次更新任务；只有系统设置页可见且任务执行中时，页面才定时刷新。

在线更新面向 Linux、root 与 systemd 安装环境，需要能访问 GitHub。旧版探针首次更新到 `v0.1.3-preview.34` 后，才能接收后续在线更新；不支持的节点会明确显示状态，不会误报成功。

更新不会重新注册节点，也不会执行任意远程脚本。GitHub 尚未发布的提交不作为更新目标。
