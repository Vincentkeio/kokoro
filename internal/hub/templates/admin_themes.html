皮肤

一键获取别人的皮肤

对方站点的主题是公开的（本来就是给人抄的）。可以填： 他的站点地址、/theme.json 完整地址， 或者 GitHub 仓库 / 子目录 / 文件链接（推荐，来源可信）。 Hub 会拉下来、逐项校验后再登记——变量名不在白名单、 值里带远程图片或分号，都会当场拒绝。

拉下来就存在你自己的面板里了，此后与来源断开关联： 对方改了他的主题，你这边不会跟着变。

导入主题

两种方式：上传 .kokoro-theme 包（能带自定义字体、背景图）， 或直接粘贴一份 theme.json（改一套「导出」最快）。 两者走同一套校验，且都会存进数据库——重启不会丢。

主题文件规范

想自己写主题，或者把这套规范丢给 AI 让它帮你生成？ 仓库里的 docs/THEME-FORMAT.md 写清了全部字段、合法变量表、 布局枚举、安全边界和一整段可直接复制的 AI 提示词， docs/themes/minimal.json 是能直接用的最小示例。

可用的 CSS 变量

改主题时用得到。写成 --kokoro- 前缀、值只能是颜色 / 长度 / 数值 / 时间 / 字体栈这几类，远程图片和 @import 一律拒绝。
