告警与通知

Telegram

Telegram 怎么配置？
  1. 在 Telegram 打开 @BotFather，发送 /newbot，按提示创建机器人，把获得的 Token 填到下方。
  2. 私聊通知：先打开自己的机器人，点 Start 或发送 /start。群组通知：先把机器人加入目标群，并确保它有发送消息的权限。
  3. 给机器人或所在群发送一条消息，然后访问 https://api.telegram.org/bot<你的Token>/getUpdates，找到对应消息的 message.chat.id，填入 Chat ID。群组 ID 的负号要保留；已有其他程序接收消息或设置了 Telegram webhook 时，需从该程序取得 Chat ID。
  4. 保存 Telegram 配置后，点“测试 Telegram”只会向 Telegram 发送测试消息。随后创建告警规则。

Token 相当于机器人密码，请勿分享含 Token 的地址。静音发送仍会收到消息，只是不响铃；免打扰时段则只记录告警、不推送。正式通知需要面板服务器能够访问 Telegram API。

Telegram 官方配置指南

Webhook

Webhook 怎么配置？

填写接收服务提供的 HTTP / HTTPS 地址，保存后点“测试 Webhook”。服务器会向此地址发送 POST 请求，格式为 application/json；接收端返回 2xx 表示接收成功。

{"title":"告警标题","body":"告警详情","level":"warning","node_id":"节点ID","ts":1700000000000}

ts 为毫秒时间戳；level 为 info、warning 或 critical，恢复通知使用 info。

适合自建接收端或能映射这些字段的自动化服务。企业微信、钉钉、飞书等机器人通常要求各自的消息格式，需通过中转服务转换，不能直接把机器人地址当作通用 Webhook。

免打扰时段

此设置同时作用于 Telegram 和 Webhook。时段内告警会记录，但不会推送；按面板服务器时区。
